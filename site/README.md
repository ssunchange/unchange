# site

公開するポートフォリオサイトのファイル。

## 構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | サイト本体。HTMLとCSSを1つにまとめてある |

ページが2枚以上になったら、CSSを別ファイルに切り出す。1枚のうちは分けないほうが編集しやすい。

## 書き換え方

`index.html` の中で、書き換える場所には **`★`** のコメントを付けてある。そこだけ触れば形になる。

1. 名前（2か所。冒頭とフッター）
2. 自己紹介文
3. できること（3つ）
4. 実績
5. 連絡先

文言はすべて仮のもの。自分の言葉に置き換える。

### 実績を1件追加する

`index.html` の「実績」の中に、コメントアウトされたブロックがある。

1. `<!--` と `-->` を消してコメントを外す
2. 中身を書き換える
3. 1件目を追加したら、`<div class="empty">実績を準備中です。</div>` の行を消す

2件目以降は、同じブロックを複製して増やす。新しいものを上に置く。

書く内容の下敷きには [`portfolio/`](../portfolio/) の記事を使う。**先に `portfolio/` に詳しく書き、そこから抜粋してサイトに載せる**という順番にすると、書き直しが減る。

## 公開の仕組み

`main` ブランチの `site/` が更新されると、[`.github/workflows/pages.yml`](../.github/workflows/pages.yml) が動いて GitHub Pages に反映される。手作業でのアップロードは不要。

反映まで1〜2分かかる。進行状況はリポジトリの **Actions** タブで見られる。

### 最初の1回だけ必要な設定

リポジトリの **Settings → Pages** を開き、**Source** を **GitHub Actions** にする。これをしないと公開されない。

## 独自ドメイン（unchange.jp）で公開する

サイトは **https://unchange.jp/** で公開する。ドメインは取得済み。

設定はすべてブラウザ上の管理画面で行う。リポジトリのファイルを変える必要はない。上から順に進める。

### 1. ドメインの持ち主であることを GitHub に登録する

他人に unchange.jp を勝手に使われないようにするための手続き。

1. GitHub 右上のアイコン → **Settings** → 左メニューの **Pages** を開く（リポジトリではなく、アカウントの Settings）
2. **Add a domain** に `unchange.jp` を入れる
3. 「`_github-pages-challenge-ssunchange` に、この文字列の TXT レコードを追加して」という指示が出る。画面は開いたままにしておく
4. ドメインの管理画面で、言われたとおりに TXT レコードを追加する（次の手順2と同じ画面で行う）
5. GitHub の画面に戻り **Verify** を押す。反映待ちで失敗したら、時間をおいて押し直す

### 2. ドメインの管理画面で DNS を設定する

DNS は「このドメイン名で来た人を、どのサーバーに案内するか」を決める設定。ドメインを買った会社の管理画面にある「DNS レコード設定」のような画面で、次の行を追加する。

`unchange.jp`（ホスト名は空欄、または `@`）の A レコード。値は4つとも追加する。

- `185.199.108.153`
- `185.199.109.153`
- `185.199.110.153`
- `185.199.111.153`

`www.unchange.jp`（ホスト名は `www`）の CNAME レコード。

- 値は `ssunchange.github.io`

すでに同じホスト名の A レコードや CNAME レコード（取得時に入っている初期設定や、ドメイン会社の「駐車ページ」向けの設定など）があれば、消してから追加する。残っていると、正しく表示されないことがある。

### 3. リポジトリにドメインを登録する

1. リポジトリの **Settings → Pages** を開く
2. **Custom domain** に `unchange.jp` を入れて **Save** を押す
3. DNS の確認が始まる。緑のチェックが付けば成功

DNS の設定が世界中に行き渡るまで、数分〜最大24時間ほどかかる。失敗表示が出ても、すぐ設定を疑わずに少し待つ。

### 4. HTTPS を有効にする

1. 同じ **Settings → Pages** の **Enforce HTTPS** にチェックを入れる
2. チェックできない（灰色の）ときは、証明書の発行待ち。しばらくしてから再度開く

### うまくいったかの確認

- https://unchange.jp/ と https://www.unchange.jp/ の両方でサイトが表示される
- アドレスバーに鍵マークが付く
- `http://` で開いても `https://` に切り替わる

## 公開前に確認すること

このリポジトリは**公開設定**になっている。`site/` に置いたものは誰でも見られる。

- クライアント名や数字を載せる前に、掲載可否を確認する（[`portfolio/README.md`](../portfolio/README.md) 参照）
- 連絡先は、公開して問題のないものだけを書く
