# site

公開するポートフォリオサイトのファイル。

## 構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | サイト本体。HTMLとCSSを1つにまとめてある |

ページが2枚以上になったら、CSSを別ファイルに切り出す。1枚のうちは分けないほうが編集しやすい。

## 書き換え方

`index.html` の中で、**まだ仮のままの場所**には **`★`** のコメントが付けてある。そこだけ触れば形になる。

| 箇所 | 状態 |
| --- | --- |
| 名前（冒頭とフッターの2か所） | 確定済み。`unchange`（不変） |
| 自己紹介文 | 仮 |
| できること（3つ） | 仮 |
| 実績 | 0件 |
| 連絡先 | 仮 |

屋号は `unchange`。リポジトリ名と揃えてあるので、公開URLも変わらない。冒頭の見出しには、読みとして「不変」を小さく添えている。

### 実績を1件追加する

`index.html` の「実績」の中に、コメントアウトされたブロックがある。

1. `<!--` と `-->` を消してコメントを外す
2. 中身を書き換える
3. 1件目を追加したら、`<div class="empty">実績を準備中です。</div>` の行を消す

2件目以降は、同じブロックを複製して増やす。新しいものを上に置く。

書く内容の下敷きには [`portfolio/`](../portfolio/) の記事を使う。**先に `portfolio/` に詳しく書き、そこから抜粋してサイトに載せる**という順番にすると、書き直しが減る。

## 公開の仕組み

`main` ブランチの `site/` が更新されると、[`.github/workflows/pages.yml`](../.github/workflows/pages.yml) が動いて GitHub Pages に反映される。手作業でのアップロードは不要。

反映まで1〜2分かかる。進行状況はリポジトリの **Actions** タブで見られる。

### 最初の1回だけ必要な設定

リポジトリの **Settings → Pages** を開き、**Source** を **GitHub Actions** にする。これをしないと公開されない。

## 公開前に確認すること

このリポジトリは**公開設定**になっている。`site/` に置いたものは誰でも見られる。

- クライアント名や数字を載せる前に、掲載可否を確認する（[`portfolio/README.md`](../portfolio/README.md) 参照）
- 連絡先は、公開して問題のないものだけを書く
